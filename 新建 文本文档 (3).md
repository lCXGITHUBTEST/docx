# BPM 卡片轻量级接口文档 V2

## 1. 概述

### 1.1 背景
为解决 `KmReviewAiCardOpenApi` 中 4 个接口返回数据量过大的问题，新增 V2 轻量版本接口。旧接口保持不变，后续由人工决策下线。

### 1.2 优化目标
- 减少接口返回字段，仅保留核心数据
- 提升接口响应速度
- 降低网络传输开销

---

## 2. 新增 VO 定义

### 2.1 AiCardInitLiteVO
卡片初始化返回对象

| 字段名       | 类型                | 说明         |
| ------------ | ------------------- | ------------ |
| fdTemplateId | String              | 模板ID       |
| fdVersionId  | String              | 版本ID       |
| fdInstanceId | String              | 卡片实例ID   |
| fdMessageId  | String              | 消息ID       |
| formData     | AiCardFormDataVO    | 卡片内容数据 |
| aiCardStatus | Integer             | 卡片状态     |
| fdCardType   | Integer             | 卡片类型     |
| config       | Map<String, Object> | 卡片渲染配置 |
| creatorNo    | String              | 创建人工号   |

### 2.2 AiCardFormDataVO
卡片表单数据对象

| 字段名     | 类型                      | 说明           |
| ---------- | ------------------------- | -------------- |
| mainData   | Map<String, Object>       | 主表数据       |
| detailData | List<Map<String, Object>> | 明细表数据列表 |

### 2.3 AiCardFormInstanceLiteVO
表单实例数据返回对象

| 字段名       | 类型             | 说明     |
| ------------ | ---------------- | -------- |
| fdInstanceId | String           | 实例ID   |
| docTitle     | String           | 文档标题 |
| status       | Integer          | 状态     |
| formData     | AiCardFormDataVO | 表单数据 |

### 2.4 AiFieldLiteVO
AI 字段轻量对象

| 字段名       | 类型   | 说明     |
| ------------ | ------ | -------- |
| fdFieldId    | String | 字段ID   |
| fdFieldName  | String | 字段名称 |
| fdFieldType  | String | 字段类型 |
| fdFieldValue | Object | 字段值   |

---

## 3. 接口清单

| 接口名称               | HTTP 方法 | 请求路径                  | 返回 VO                    |
| ---------------------- | --------- | ------------------------- | -------------------------- |
| initV2                 | POST      | `/initV2`                 | `AiCardInitLiteVO`         |
| initOrSaveAiCardV2     | POST      | `/initOrSaveAiCardV2`     | `AiCardInitLiteVO`         |
| loadFormInstanceDataV2 | POST      | `/loadFormInstanceDataV2` | `AiCardFormInstanceLiteVO` |
| getFormAiFieldsV2      | POST      | `/getFormAiFieldsV2`      | `List<AiFieldLiteVO>`      |

---

## 4. 接口详情

### 4.1 initV2 - 初始化卡片（轻量版）

**接口描述**：初始化 BPM 卡片，返回卡片核心数据，不包含完整模板信息和表单配置。

**请求路径**：`POST /initV2`

**请求参数**：

| 参数名       | 类型   | 必填 | 说明                 |
| ------------ | ------ | ---- | -------------------- |
| fdTemplateId | String | 是   | 模板ID               |
| fdInstanceId | String | 否   | 实例ID（编辑时传入） |

**响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "fdTemplateId": "TPL001",
    "fdVersionId": "V1.0",
    "fdInstanceId": "INS123456",
    "fdMessageId": "MSG789012",
    "creatorNo": "100234",
    "formData": {
      "mainData": {
        "title": "出差申请",
        "applicant": "张三",
        "applyDate": "2026-04-01"
      },
      "detailData": [
        {
          "travelDate": "2026-04-02",
          "destination": "上海",
          "expense": 1200
        }
      ]
    },
    "aiCardStatus": 1,
    "fdCardType": 2,
    "config": {
      "theme": "default",
      "layout": "standard"
    }
  }
}
```

### 4.2 initOrSaveAiCardV2 - 初始化或保存卡片（轻量版）

**接口描述**：初始化或保存 AI 卡片，返回卡片核心数据。

**请求路径**：`POST /initOrSaveAiCardV2`

**请求参数**：

| 参数名       | 类型             | 必填 | 说明                 |
| :----------- | :--------------- | :--- | :------------------- |
| fdTemplateId | String           | 是   | 模板ID               |
| fdInstanceId | String           | 否   | 实例ID（编辑时传入） |
| formData     | AiCardFormDataVO | 否   | 卡片表单数据         |
| aiCardStatus | Integer          | 否   | 卡片状态             |
| fdCardType   | Integer          | 否   | 卡片类型             |

**响应示例**：

json

```
{
  "code": 200,
  "message": "success",
  "data": {
    "fdTemplateId": "TPL001",
    "fdVersionId": "V1.0",
    "fdInstanceId": "INS123456",
    "fdMessageId": "MSG789012",
    "creatorNo": "100234",
    "formData": {
      "mainData": {
        "title": "出差申请",
        "applicant": "张三",
        "status": "已提交"
      },
      "detailData": []
    },
    "aiCardStatus": 2,
    "fdCardType": 2,
    "config": {
      "theme": "default",
      "layout": "standard"
    }
  }
}
```

### 4.3 loadFormInstanceDataV2 - 加载表单实例数据（轻量版）

**接口描述**：根据实例 ID 加载表单数据，仅返回核心字段，不包含权限、传阅人等冗余信息。

**请求路径**：`POST /loadFormInstanceDataV2`

**请求参数**：

| 参数名       | 类型   | 必填 | 说明   |
| :----------- | :----- | :--- | :----- |
| fdInstanceId | String | 是   | 实例ID |

**响应示例**：

json

```
{
  "code": 200,
  "message": "success",
  "data": {
    "fdInstanceId": "INS123456",
    "docTitle": "张三的出差申请",
    "status": 1,
    "formData": {
      "mainData": {
        "title": "出差申请",
        "applicant": "张三",
        "department": "技术部",
        "destination": "上海",
        "startDate": "2026-04-02",
        "endDate": "2026-04-05"
      },
      "detailData": [
        {
          "date": "2026-04-02",
          "expenseType": "交通费",
          "amount": 500
        },
        {
          "date": "2026-04-03",
          "expenseType": "住宿费",
          "amount": 800
        }
      ]
    }
  }
}
```

**接口描述**：获取表单中 AI 相关字段列表，返回轻量化字段信息。

**请求路径**：`POST /getFormAiFieldsV2`

**请求参数**：

| 参数名       | 类型   | 必填 | 说明   |
| :----------- | :----- | :--- | :----- |
| fdTemplateId | String | 是   | 模板ID |
| fdInstanceId | String | 否   | 实例ID |
